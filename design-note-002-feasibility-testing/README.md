# Design Note #002 — A Structured Feasibility-Testing Workflow for High-Risk, Low-Data Decisions

Reusable prompt template and workflow documentation for pressure-testing high-risk micro-business ideas before committing capital.

## Links
- Full write-up: [Ash's Daily Blog](https://ashdaily.blog/002-structured-feasibility-testing-workflow/)

## Workflow Stages
1. **Define Boundary Conditions** — Lock down hard constraints.
2. **Convert Intuition into a Unit-Economics Model** — Turn feelings into numeric models.
3. **Force Adversarial Risk Review** — Shift from "is this good?" to "where does this fail?".
4. **Propose Risk-Reduced Alternatives** — Tiered paths from high to low risk.
5. **Stress-Test the Capital Buffer** — Model pessimistic early-traffic runway.
6. **Deliver a Conditional Recommendation** — Actionable preconditions instead of yes/no.
